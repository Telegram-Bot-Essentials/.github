# .github

Org-wide community health files for [Telegram Bot Essentials](https://github.com/Telegram-Bot-Essentials).

GitHub applies the files here — `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, and
the `.github/ISSUE_TEMPLATE` / `pull_request_template.md` set — as defaults to every repo in
the org that doesn't ship its own copy. `profile/README.md` renders on the
[org profile page](https://github.com/Telegram-Bot-Essentials).
